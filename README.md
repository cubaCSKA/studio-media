# studio-media

Хостинг готовых роликов для планировщика Metricool.

Metricool принимает только публичную ссылку на видео — файл напрямую он не
берёт. Этот репозиторий и есть такая ссылка: ролики заливаются в релизы,
каждый получает прямой адрес вида
`releases/download/<дата>/<имя>.mp4`, и планировщик скачивает по нему без
авторизации.

Репозиторий **публичный намеренно**: приватный отдаёт файлы только по токену,
а планировщику его взять неоткуда. Ничего кроме видео здесь нет — код, ключи
и базы доноров лежат в отдельном приватном репозитории.

Ролики нужны только до момента публикации: Metricool копирует видео к себе
сразу при постановке в очередь. Старые релизы можно удалять.
